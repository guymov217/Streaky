# Dr Bellini 🩺

אפליקציית מטלות יומיות ללימודי רפואה, בסגנון משחקי, עם ד״ר בליני הצ׳יוואוה. בונים רצף (Streak) על כל יום שבו משלימים את כל המטלות.

## מה יש באפליקציה
- **רשימת מטלות יומית** שהמשתמש מזין בעצמו, עם אייקון לכל מטלה: UWorld, Sketchy, Anki, First Aid, NBME או כללי (נבחר אוטומטית לפי שם המטלה). כל בוקר המטלות מתאפסות.
- **רצף 🔥:** גדל ב‑1 על כל יום שבו כל המטלות הושלמו. אם מדלגים על יום, הרצף מתאפס (השיא 🏆 נשמר).
- **XP 💎:** ‏10 על כל מטלה ובונוס 20 על יום מושלם.
- **ד״ר בליני** (צ׳יוואוה) שמגיב להתקדמות (ומתעצבן אחרי 20:00 אם לא סיימת), פס התקדמות ולוח שבועי.
- **מסך חגיגה** עם קונפטי וצלילים כשמסיימים את כל מטלות היום.
- **תזכורות חכמות 🔔:** התראה בשעות שבוחרים, **רק אם עוד לא סיימת**. ההודעה מותאמת להתקדמות שלך, למשל "🔥 הרצף שלך בסכנה! נשארו לך 2 מטלות".
- **שני סגנונות התראות:**
  - 😈 **הומור שחור** (ברירת המחדל), למשל "🩺 לא תלמד/י, מטופלים ימותו", כולל בדיחות על מטלה ספציפית שלא ביצעת.
  - 😊 **עדין**.
  בוחרים את הסגנון במסך התזכורות 🔔.
- עובדת גם בלי אינטרנט ואפשר להתקין אותה למסך הבית. הנתונים נשמרים במכשיר.

## 🤖 התקנה באנדרואיד: אפליקציה אמיתית, בלי תלות בכלום

מורידים את הקובץ ומתקינים. האפליקציה כולה נמצאת בטלפון: עובדת בלי אינטרנט, הנתונים נשמרים במכשיר, והתזכורות מתוזמנות בטלפון עצמו (בלי שרת).

**קישור הורדה קבוע:** https://github.com/guymov217/Streaky/releases/latest/download/dr-bellini.apk

1. פותחים את הקישור בטלפון ומורידים את `dr-bellini.apk`.
2. פותחים את הקובץ שירד. אם מופיעה הודעה על התקנה ממקור לא ידוע, לוחצים "הגדרות", מאפשרים וחוזרים (פעם אחת).
3. לוחצים "התקן". אם Play Protect מזהיר, בוחרים "פרטים נוספים" ← "התקן בכל זאת".

עדכונים: כל שינוי בקוד בונה גרסה חדשה אוטומטית. מורידים שוב מאותו קישור ומתקינים מעל הקיימת. הרצף והמטלות נשמרים.

### הגדרה חד־פעמית לבעל המאגר: מפתח חתימה
GitHub בונה את ה‑APK אוטומטית (`.github/workflows/android.yml`). כדי שתתפרסם גרסה להורדה, מוסיפים פעם אחת סוד אחד:
1. פותחים את https://github.com/guymov217/Streaky/settings/secrets/actions/new
2. ב‑**Name** כותבים `ANDROID_KEYSTORE`.
3. ב‑**Secret** מדביקים את הערך של מפתח החתימה (שורה אחת ארוכה), ולוחצים **Add secret**.

**חשוב:** שומרים גיבוי של הערך במקום בטוח. בלעדיו לא ניתן לפרסם עדכונים שיותקנו מעל הגרסה הקיימת. אסור להכניס אותו לקוד במאגר. עד שהסוד מוגדר, כל בנייה נחתמת במפתח זמני ולא מתפרסמת.

## 🍎 התקנה באייפון

אפל לא מאפשרת להתקין קובץ אפליקציה בלי App Store. באייפון מוסיפים את Dr Bellini למסך הבית מ‑Safari. אחרי ההוספה היא נפתחת כמו אפליקציה ועובדת גם בלי אינטרנט, אבל התזכורות באייפון מגיעות משרת התזכורות ב‑Netlify.

## הקמת האתר ושרת התזכורות (פעם אחת, כ‑10 דקות)

### שלב 1: להעלות לאוויר ב‑Netlify (חינם)
1. היכנס ל‑**app.netlify.com** והירשם עם חשבון ה‑GitHub שלך.
2. לחץ **Add new site** ← **Import an existing project** ← **GitHub**.
3. בחר את המאגר `streaky`. אם הוא לא מופיע, לחץ בתחתית הרשימה על **Configure the Netlify app on GitHub** ותן גישה למאגר `streaky`.
4. בשדה **Branch to deploy** השאר `main`.
5. את שאר ההגדרות השאר כמו שהן (הן נקראות אוטומטית מהקובץ `netlify.toml`) ולחץ **Deploy**.
6. אחרי דקה תקבל כתובת כמו `https://random-name.netlify.app`. אפשר לשנות אותה ב‑**Site configuration** ← **Change site name**, למשל ל‑`dr-bellini`.

אין צורך להגדיר מפתחות או סיסמאות: השרת יוצר בעצמו את מפתחות ההתראות בפעם הראשונה.
מעכשיו כל עדכון לענף יעלה לאוויר אוטומטית.

### שליחה למשתמשים
שולחים את הכתובת מ‑Netlify, וזה הכל. מי שפותח את הקישור בדפדפן רואה מסך "התקן את Dr Bellini":
- **באייפון:** הוראות בשלושה צעדים עם האייקונים של Safari.
- **באנדרואיד:** כפתור "הורד את האפליקציה" (קובץ APK) עם הוראות. אם עוד לא פורסמה גרסה, מוצגת התקנה דרך הדפדפן.
- **במחשב:** קוד QR שסורקים עם הטלפון.

אין צורך ב‑App Store או ב‑Google Play.

### שלב 2: להתקין באייפון (ידנית)
1. פתח את הכתובת ב‑**Safari** (לא ב‑Chrome).
2. לחץ על כפתור **השיתוף** ⬆️ בתחתית המסך.
3. בחר **"הוסף למסך הבית"** ← **הוסף**.
4. פתח את Dr Bellini **מהאייקון** במסך הבית.

### שלב 3: להפעיל תזכורות
1. באפליקציה (שנפתחה מהאייקון) לחץ על הפעמון 🔔 למעלה.
2. בחר שעות (ברירת המחדל: 09:00 ו‑20:00) ולחץ **הפעל התראות**.
3. אשר את ההודעה של האייפון שמבקשת הרשאה לשלוח התראות.

נדרש iOS 16.4 ומעלה. ההתראות נשלחות בדיוק של עד 15 דקות מהשעה שנבחרה.

## פיתוח

```bash
npm install
npm start              # מגיש את src בכתובת http://localhost:5173 (בלי שרת התזכורות)
npm test               # בדיקות לוגיקת הרצף והתזכורות
npm run android:sync   # מעתיק את src לפרויקט האנדרואיד (android/)
```

**מבנה:** האפליקציה עצמה נמצאת ב‑`src/` (HTML/CSS/JS בלי שלב בנייה). שרת התזכורות נמצא ב‑`netlify/functions/`:
- `sync`: שמירת המנוי וההתקדמות היומית.
- `config`: המפתח הציבורי להתראות.
- `remind`: רץ כל 15 דקות ושולח התראות.

הנתונים בשרת נשמרים ב‑Netlify Blobs.

**אנדרואיד:** `android/` הוא פרויקט Capacitor (מזהה `app.drbellini.study`) שעוטף את `src/`. באפליקציה המותקנת התזכורות מתוזמנות בטלפון (`src/native.js`, `src/local-reminders.js`) ולא דרך השרת.
